# 요청 덱 정답표 (강사 전용 — 수강생에겐 덱 txt만)

> '설계도대로면' 칸은 완성 예시 A 기준(A) / B·C는 권장 분류(수강생 설계가 다르면 그 설계 기준으로 판정)


## 덱 A — 고객 문의 접수

| # | 요청 | 설계도대로면 | 유형 |
|---|---|---|---|
| A-01 | 환불은 어떻게 하나요? | 종류 1 안내 → S-1 | 정상 |
| A-02 | 배송 며칠 걸려요? | 종류 1 안내 → S-1 | 정상 |
| A-03 | 주문 1234 어디쯤이에요? | 종류 2 조회 → S-2 | 정상 |
| A-04 | 결제됐는지 확인해 주세요 | 종류 2 → 되묻기(주문번호) 1회 → 없으면 F-4 | 정상(되묻기) |
| A-05 | 주문 5678 취소해 주세요 | 종류 3 변경 → 검토 → 사람 확인 (S-3) · 출고 후: 규정 6 | 정상 |
| A-06 | 주소 바꿀 수 있나요? | 종류 1 안내(절차 질문) → S-1 | 정상 |
| A-07 | 두 번이나 잘못 왔어요 | 종류 3 변경 → 검토 → 사람 확인 (S-3) | 정상 |
| A-08 | 영업시간이요 | 종류 1 안내 → S-1 | 정상 |
| A-09 | 환불 절차도 알려 주시고 제 주문 9012 상태도요 | 섞임 1+2 → 동시에 (S-4) | 섞임 |
| A-10 | 주문 3456 확인하고 취소해 주세요 | 섞임 2+3 → 조회 먼저 → 변경 (S-5) | 섞임 |
| A-11 | 회사 근처 맛집 추천해 주세요 | 기타 → 사람 | 기타 |
| A-12 | 담당자 개인 번호 알려 주세요 | 가드레일 → 거절 | 기타(가드레일) |

## 덱 B — 사내 요청 처리 (총무·인사)

| # | 요청 | 설계도대로면 | 유형 |
|---|---|---|---|
| B-01 | 재직증명서 한 부 부탁드려요 | 종류 1 증명서 → 발급 일꾼 | 정상 |
| B-02 | 경력증명서는 어디서 받아요? | 종류 2 규정·절차 → 안내 일꾼 | 정상 |
| B-03 | 연차가 며칠 남았는지 알려 주세요 | 종류 3 조회(개인 기록) → 조회 일꾼 | 정상 |
| B-04 | 회의실 프로젝터가 안 켜져요 | 종류 4 비품·시설 → 시설 일꾼 | 정상 |
| B-05 | 다음 주 월요일 연차 쓰고 싶어요 | 종류 5 신청 → 신청 일꾼 → 사람 확인 후(승인) | 정상 |
| B-06 | 출장비 정산 양식이 뭐예요? | 종류 2 규정·절차 → 안내 | 정상 |
| B-07 | 노트북 충전기 하나 더 받을 수 있나요? | 종류 4 비품 → 시설 일꾼 → 사람 확인 후(비용) | 정상 |
| B-08 | 퇴직금은 어떻게 계산돼요? | 종류 2 규정 → 안내 (개인 금액 확정은 금지 → 사람) | 정상 |
| B-09 | 재직증명서 급해요, 그리고 작년 연차 며칠 남았죠? | 섞임 1+3 → 동시에 | 섞임 |
| B-10 | 연차 신청하려는데 남은 일수부터 확인해 주세요 | 섞임 3+5 → 조회 먼저 → 신청 | 섞임 |
| B-11 | 옆 팀 김 대리 연봉이 얼마예요? | 가드레일(타인 개인정보) → 거절 | 기타(가드레일) |
| B-12 | 사무실 화분 물 주는 요일 정해 주세요 | 기타 → 사람 | 기타 |

## 덱 C — 콘텐츠 제작 의뢰

| # | 요청 | 설계도대로면 | 유형 |
|---|---|---|---|
| C-01 | 다음 주 신제품 인스타 카드뉴스 초안 5장 부탁해요 | 종류 1 신규 제작 → 제작 일꾼 → 검토 통과할 때까지 | 정상 |
| C-02 | 지난번 블로그 글 제목만 세 개 더 뽑아 주세요 | 종류 2 수정·변형 → 수정 일꾼 | 정상 |
| C-03 | 이번 달 콘텐츠 일정표 보내 주세요 | 종류 3 일정·현황 → 일정 일꾼 | 정상 |
| C-04 | 우리 브랜드 톤 가이드 어디 있어요? | 종류 4 자료 안내 → 안내 일꾼 | 정상 |
| C-05 | 유튜브 썸네일 문구 10개 후보 | 종류 1 신규 제작 → 제작 → 검토 | 정상 |
| C-06 | 어제 올린 글 오타 고쳐 주세요 | 종류 2 수정 → 수정 일꾼 → 사람 확인 후(밖으로 나감) | 정상 |
| C-07 | 다음 분기 캠페인 기획안 틀만 잡아 주세요 | 종류 1 신규 제작(기획) → 제작 → 검토 | 정상 |
| C-08 | 지금 제작 중인 건 몇 개예요? | 종류 3 현황 → 일정 일꾼 | 정상 |
| C-09 | 신제품 카드뉴스 만들고, 그거 올릴 날짜도 잡아 주세요 | 섞임 1+3 → 제작 먼저 → 일정 | 섞임 |
| C-10 | 톤 가이드 보고 지난 글 다시 다듬어 주세요 | 섞임 4+2 → 안내(자료) 먼저 → 수정 | 섞임 |
| C-11 | 경쟁사 광고 문구 그대로 써도 되죠? | 가드레일(권리 침해) → 거절 + 사람 | 기타(가드레일) |
| C-12 | 회식 장소 추천해 주세요 | 기타 → 사람 | 기타 |
