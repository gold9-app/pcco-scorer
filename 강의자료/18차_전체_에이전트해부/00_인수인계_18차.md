## 3. 핵심 정의 (모든 자료에서 이 문구 그대로)

- **두 축** — 속: 누가 판단하나(프로그램·LLM·에이전트) / 겉: 어디 살고 누가 쓰나(도구·앱·서비스). "속과 겉은 따로 고른다." 격자 에이전트 줄: 도구 칸 = 영상 공장(지금, 작업대 안) → 서비스 칸 = 무인판(미래) = "MCP now → API later".
- **에이전트** — 목표를 받고, 손(도구)을 써서, 결과를 보고, 다음 행동을 스스로 정하는 AI. ≠ 똑똑한 LLM — 차이는 **손과 루프**.
- **작업대 vs 에이전트** — 빌려 주는 것(머리·손·루프) / 설계하는 사람의 몫(규칙·일꾼·보내는 표·남기는 곳). "보이지 않는 건 빌린 것"(해부도).
- **라우팅** — 접수창구, 보기만 하고 보낸다. 세 군데(요청→일꾼 / 행동→도구 / 난이도→모델). 방식 3(규칙·분류 AI·유사 사례). **빠뜨리는 셋**: 모르는 요청(기본 경로 = 사람)·섞인 요청(쪼개나 우선순위냐)·잘못 간 요청(돌려보내는 길). "라우팅은 코드가 아니라 분류 기준 문장이다."
- **오케스트레이션** — 순서·상태·호출로 잇고 책임지는 것. 패턴 4 줄·나눔·감독·되돌림(고르는 질문 4). 얇은 지휘자(판단은 일꾼이, 규칙은 지침이). **일꾼끼리 머리를 공유하지 않는다 → 파일·계약**. 사람 관문 = 돈·밖·되돌릴 수 없음.
- **여정 ①** 접수→종류 판정(문장을 봤다)→담당(내 대화를 모른다)→결과→기록 / **여정 ②** 섞임→사람→표 한 줄("성과 먼저, 그 결과로 소재" = 줄)→다시→두 이름. "고친 건 코드가 아니라 표의 한 줄."
- **직무별 예시** 마케터(소재·성과·일정 / 나 / 줄) · 인사·총무(증명서·규정·비품 / 담당자 확인 / 감독) · 영업·CS(견적·클레임·납기 / 사람, 클레임은 항상 / 나눔). "내 일이면?" 1분 침묵, 종이·순회·발표 없음.
